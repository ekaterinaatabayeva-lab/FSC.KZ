# FSC.KZ — сайт компании

Статичный адаптивный сайт (HTML/CSS/JS, без сборки и зависимостей).

## Структура

```
index.html
assets/
  css/style.css
  js/main.js
  images/        ← сюда добавить реальные фото, когда будут готовы
```

## Что нужно донастроить

Все контактные данные вынесены в один блок конфигурации —
`assets/js/main.js`, объект `CONFIG` в самом верху файла:

```js
const CONFIG = {
  whatsappNumber: "77771221309",
  whatsappDefaultText: "...",
  address: "...",
  email: "...",
  instagram: "...",
  telegram: "...",
};
```

Замените значения на реальные — они автоматически подставятся во все
места на сайте (шапка, футер, блок «Контакты», кнопки WhatsApp).

## Фото

Сейчас вместо фото используются лёгкие SVG-иллюстрации (склад, хранилище).
Когда пришлёте реальные фото объектов/команды — положите их в
`assets/images/` и замените `<svg>`-блоки на `<img>` в `index.html`
(разделы `.hero__visual` и `.about__media`).

## Локальный просмотр

Просто откройте `index.html` в браузере, либо запустите локальный сервер:

```
python3 -m http.server 8000
```

и откройте `http://localhost:8000`.

## Деплой

Сайт полностью статичный — подходит любой статик-хостинг (Netlify,
Vercel, GitHub Pages, обычный shared-хостинг). Достаточно загрузить
содержимое папки как есть.
